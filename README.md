# React Lab ⚛️

A growing collection of React components, practical exercises, and small projects developed through hands-on learning and teaching.

This repository serves as a practical lab for exploring React concepts, strengthening implementation skills, and creating examples that can also be used in front-end development education.

## 🛠️ Tech Stack

* React
* Vite
* JavaScript
* Tailwind CSS

## 📚 Topics

This lab covers React concepts through practical implementation, including:

* Components
* Functional Components
* Class Components
* Props
* State
* Events
* Component Communication
* Forms
* Reusable Components
* And more...

## 🎯 Purpose

The goal of this repository is to strengthen React implementation skills through hands-on practice while developing clear, practical examples for teaching front-end development concepts.

## 🚀 Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## 📁 Project Structure

```text
src/
├── components/
├── App.jsx
├── main.jsx
└── index.css
```

## 📌 Projects & Exercises

Exercises and small projects are added progressively as new React concepts are learned, implemented, and explored through teaching.
